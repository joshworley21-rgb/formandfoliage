# Design System & Token Standards

- Icons: Exclusively use lucide-react. Set consistent sizing classes:
  - Small / metadata: size-4 (16px)
  - Navigation / lists: size-5 (20px)
  - Primary hero / buttons: size-6 (24px)
- Spacing & Rhythm: Stick strictly to 4px multiples (p-2, p-4, gap-3, gap-6).
- Dark Mode / Contrast: Pair all text colors with dark variants (text-slate-900 dark:text-slate-100).
